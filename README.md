# 🌤️ Atmos — Weather Intelligence

A modern, responsive weather dashboard built with **HTML, CSS, and JavaScript**. Atmos uses free weather APIs to provide real-time weather information, forecasts, air quality data, and an interactive map in a clean and modern interface.

![Atmos Weather Dashboard](https://placehold.co/1200x650/0b1020/ffffff?text=Atmos+Weather+Dashboard)

## ✨ Features

* 🌡️ **Current Weather**

  * Temperature
  * Feels-like temperature
  * Weather condition
  * Humidity
  * Wind speed and direction
  * Atmospheric pressure
  * Visibility

* 🌧️ **Weather Forecast**

  * 24-hour temperature forecast
  * 5-day weather forecast
  * Rain probability
  * Expected precipitation
  * UV index

* 🫁 **Air Quality**

  * US AQI
  * PM2.5
  * PM10
  * Ozone
  * Easy-to-understand air quality status

* 🗺️ **Interactive Map**

  * Leaflet-powered map
  * OpenStreetMap integration
  * Click anywhere on the map to check weather at that location
  * Automatic weather marker updates

* 📍 **Location Features**

  * Search for cities and locations
  * Browser-based "My Location"
  * Recent searches
  * Favorite locations

* 🎨 **Modern UI**

  * Premium glassmorphism interface
  * Responsive design
  * Dark and light themes
  * °C / °F temperature switching
  * Dynamic weather animations
  * Weather-based recommendations

## 🌐 APIs

### Open-Meteo

Atmos uses the Open-Meteo API for weather forecasts and geocoding.

No API key is required for the basic project usage.

### Open-Meteo Air Quality

Air quality information is provided through the Open-Meteo Air Quality API.

### OpenStreetMap

The interactive map uses OpenStreetMap data through Leaflet.

> Map data © OpenStreetMap contributors.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/atmos-weather.git
```

### 2. Open the project

```bash
cd atmos-weather
```

### 3. Run the application

Simply open:

```text
index.html
```

For the best experience, run it through a local development server or deploy it using GitHub Pages.

## 🎯 Project Goals

The goal of Atmos is to demonstrate how a modern frontend application can combine multiple APIs, interactive maps, data visualization, browser features, and responsive UI into a single practical project.

This project also focuses on:

* API integration
* Asynchronous JavaScript
* Data visualization
* Geolocation
* Local storage
* Responsive web design
* Interactive UI development
